# KELOMPOK2_PEMOGRAMAN-MOBILE_F
EcoPower adalah aplikasi mobile berbasis Flutter yang dirancang untuk mengenalkan berbagai sumber energi terbarukan melalui antarmuka interaktif. Aplikasi ini mengimplementasikan tiga jenis gesture, yaitu Tap, Long Press, dan Drag and Drop, untuk memberikan pengalaman belajar yang menarik dan mudah dipahami.
