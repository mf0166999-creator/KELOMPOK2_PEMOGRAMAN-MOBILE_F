# EcoPower 🌱

**EcoPower** adalah aplikasi mobile berbasis Flutter yang bertujuan untuk memperkenalkan berbagai sumber energi terbarukan melalui tampilan yang interaktif dan mudah digunakan.

## Fitur Utama

* **Tap Gesture:** Mengubah warna kartu sumber energi ketika ditekan.
* **Long Press Gesture:** Menampilkan informasi mengenai sumber energi melalui dialog.
* **Drag and Drop Gesture:** Memungkinkan pengguna menyeret kartu sumber energi ke area pasangan yang sesuai.
* **Visual Feedback:** Memberikan perubahan warna dan pesan untuk menunjukkan hasil interaksi pengguna.
* **Reset:** Mengembalikan demonstrasi interaksi ke kondisi awal.

## Teknologi yang Digunakan

* Flutter
* Dart
* Material Design
* StatefulWidget dan `setState()`
* InkWell, Draggable, dan DragTarget

## Tujuan Proyek

Proyek ini dibuat untuk memenuhi tugas pengembangan aplikasi mobile menggunakan Flutter, khususnya dalam penerapan gesture dan pengelolaan perubahan tampilan berdasarkan interaksi pengguna.

Selain itu, EcoPower diharapkan dapat meningkatkan pemahaman pengguna mengenai energi terbarukan dan mendukung edukasi tentang penggunaan energi yang lebih ramah lingkungan.

## Struktur Aplikasi

Aplikasi menggunakan `EcoPowerApp` sebagai widget utama dan `EcoPowerDashboard` sebagai halaman utama. Antarmuka disusun menggunakan berbagai widget Flutter, seperti Scaffold, Column, Card, dan GridView, agar tampilan lebih terstruktur.
